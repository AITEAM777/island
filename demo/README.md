# Volcanic Island — демовідео

Горизонтальний MP4, рівно 40 секунд, 1280×720, 24 кадри/с, H.264 + AAC. Українські підписи вбудовано у відео. Атмосферний звук створено процедурно спеціально для цієї демонстрації; сторонні музичні записи не використовуються.

Сценарій:

- 00:00–00:05 — загальний вигляд, плавне обертання й наближення.
- 00:05–00:12 — зміна течії, три сплески від кліків по воді.
- 00:12–00:18 — додавання риб, зміна швидкості, приховування й показ.
- 00:18–00:25 — хмарність, дощ і гроза.
- 00:25–00:34 — виверження, лава й викиди, поступове згасання.
- 00:34–00:40 — нічне й денне освітлення, повернення камери.

Знято реальний застосунок із коміту 7504f7db18cc34ce54fda585cf3aebb912a73ff6. Браузер рендерить кадри з фіксованим кроком симуляції 1/24 секунди; це забезпечує плавний результат незалежно від швидкості програмного GPU. Керування запускає наявні обробники застосунку, кліки по воді використовують його raycasting. Вихідний HTML і сайт під час запису не змінювалися.

Відтворення: capture-demo.cjs записує кадри через Playwright, create_soundtrack.py створює WAV, render-demo.py монтує MP4 і перевіряє кодеки, розмір кадру, кількість кадрів та тривалість через ffprobe.
